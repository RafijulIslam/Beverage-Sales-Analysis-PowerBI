📊 Beverage Sales Analysis 2022
Overview
The Sales Performance Dashboard is an interactive Power BI report designed to analyze beverage sales performance across different regions and brands. It provides valuable business insights through key performance indicators (KPIs), sales trends, profitability analysis, and dynamic filtering capabilities.

This dashboard helps stakeholders monitor sales performance, identify high-performing products, and support data-driven business decisions.
